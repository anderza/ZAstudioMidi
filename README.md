# ZaStudio

Android-приложение, которое играет партию ударных из MIDI-файлов записанными сэмплами и даёт добавить бас, синтезаторы, клавишные, струнные, гитары и духовые в «Студии». Звуки инструментов взяты из GeneralUser GS v2.0.3 (S. Christian Collins, http://www.schristiancollins.com, лицензия в `web/LICENSE-GeneralUser-GS.txt`) и играются как в SoundFont-плеере: слои по силе нажатия, затухание, фильтр, стерео. Ударные: сэмплы FluidR3 GM (лицензия MIT). Умеет делать MIDI-проект из аудиофайла и из табов Guitar Pro (.gp3, .gp4, .gp5) и сохранять проект в MIDI-файл.
Установки: Стандарт, Рок, Панк-рок, Модерн, Поп, Электро 808. Есть миксер с фейдерами, Overhead и Ambience, редактор дорожек и сохранение.

## Скачать APK

Готовый APK лежит в последнем релизе: **Releases → Latest → ZaStudio.apk**. Его собирает GitHub Actions при каждом push в `main`.

## Как устроено

- `web/template.html` — сам плеер (HTML, CSS, JS).
- `web/kitdata.json` — встроенные сэмплы барабанов.
- `web/instdata.json` — инструменты: для каждого сэмплы (`s`), огибающие и фильтры (`e`) и зоны (`z`: клавиши, сила нажатия, высота, петля, громкость, панорама).
- `web/build.py` собирает из них `app/src/main/assets/index.html`, единый файл, который работает без интернета.
- `app/` — Android-обёртка: WebView, выбор MIDI-файлов, сохранение MIDI в «Загрузки», кнопка «Назад» закрывает открытые панели.

Сборка локально: `python3 web/build.py && ./gradlew assembleRelease` (нужны JDK 17 и Android SDK).
